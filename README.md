# Neural Network Recognising Letters

## A functional project which uses NumPy to implement a simple neural network using linear algebra

This project is my first introduction into the mechanics behind machine learning which includes the following concepts:

* Implementing a generalised neural network as an object
* Implementing forward and back propagation using NumPy's array type and operations
* Implementing a batch training method in order to train the neural network

## How to use this project

1. Clone this repository
2. Type in the command 'pip install -r requirements.txt'
3. Download the following dataset: https://www.kaggle.com/datasets/sachinpatel21/az-handwritten-alphabets-in-csv-format
4. Run the code and feel free to change the index specified to test the model's accuracy on different letters
5. It is also possible to change the networks shape by passing different parameters to the NeuralNetwork object
